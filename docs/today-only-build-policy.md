# AUREX three-day fixture discovery

Mini App slip builds examine SportyBet's upcoming fixture catalog using Africa/Lagos calendar dates. Always try **today first** and verify eligible active markets, not merely a scheduled fixture listing. When that day has *zero eligible active markets*, try **tomorrow**; if that also has zero, try **the following day**. Never select beyond two days ahead or mix separate calendar days to fill a requested count. When a day has at least one eligible market, return only that day's selection(s) and honestly report any shortfall. If all three days lack verified eligible active markets, return a truthful no-games message. Provider/network failures must not be mistaken for no games.

Expose `scheduleDate`, `dayOffset` and a human-readable schedule in each successful build. In Explore, choose the first of these three days with upcoming or live fixture listings (without claiming individual markets have been verified), and display the actual date. Filtering a search down to zero rows must not trigger an alternative calendar date. Preview is not evidence that real provider data is available; validate with Telegram authentication.
